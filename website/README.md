# pbid website

Local preview of the bidding desk. The home page lists one public NFT, records bids in browser state, and hides amounts from anyone who is not the seller. The reserve stays in this browser. Nothing on this page submits a transaction, and the five NFT standards are not implemented here.

The future program lives at the repository root. See the root `README.md` for the standard byte and the CPI each standard requires. Core collection plugins constrain Core assets. They are not another standard.

No program id is set in this app.
